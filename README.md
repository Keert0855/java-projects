# java-projects
Projects made during AP Computer Science A or Discrete Mathematics

* **Continued Fraction Generator (`ContinuedFractionIrrational.java`)**
  * Computes and displays continued fraction expansions for real and irrational numbers.
  * Handles precision limits and mathematical formatting.

* **Discrete Mathematics Tools (`Discrete.java` & `DiscreteE.java`)**
  * Implements algorithms and computational tools explored in discrete math concepts. Helper classes for above.
